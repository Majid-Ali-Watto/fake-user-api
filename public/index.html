Fake User API: a free REST API with 100 fake users

A dummy backend so you can focus on the front end: users CRUD, JWT login and refresh, roles, pagination and CORS, with no sign-up or API key. Try it below, then call it from your own code.

Demo accounts

        
Log in with password password123 as admin@example.com, moderator@example.com or user@example.com. Every seeded user shares that password. Send the access token as Authorization: Bearer <token>. Access tokens last 1 hour, refresh tokens 7 days. Demo accounts are read-only; use /auth/register to create your own.

      

      
Open /api for a JSON list of these endpoints. Data is kept in memory and regenerated when the server restarts, so changes are temporary. Limits per IP every 15 minutes: 300 requests, at most 60 of them writes.

Frequently asked questions

      

        What is the Fake User API?
        
A free, public REST API that returns 100 randomly generated users (name, email, username, phone, age, location, occupation and more). Use it as placeholder data while building front ends, writing tutorials, or testing HTTP clients.

      

      

        Do I need an API key?
        
No. There is no sign-up and no key. Requests are limited per IP address to keep the service available for everyone.

      

      

        Can I call it from the browser?
        
Yes. CORS is enabled, so fetch and axios calls from any origin work.

      

      

        How does authentication work?
        
Log in at POST /api/v1/auth/login to get a JWT access token and refresh token. Send the access token in the Authorization: Bearer header. Missing, expired or wrong-type tokens return 401, and a missing role returns 403, so you can build and test real login, refresh and role-based UI against it. The secret is public, so never use it for real data.

      

      

        Does it support create, update and delete?
        
Yes. POST, PATCH, PUT and DELETE all work and are validated. Data is kept in memory and resets when the server restarts, so changes are temporary.

      

      

        How do I paginate results?
        
Use ?page= and ?limit= (up to 100 per page). The response includes total and totalPages.
